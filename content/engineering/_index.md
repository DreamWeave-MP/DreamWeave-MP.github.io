DreamWeave's internal projects are where migration techniques, runtime boundaries, and tooling primitives are proven before they become part of the next engagement.

## Jess

A Rust-first software substrate with Luau at the center of the programmable boundary. Jess is built around the idea that reusable capability should accumulate instead of being reimplemented application by application.

## L3i

Lowering, code generation, instancing, sandboxing, and the execution boundary beneath Jess.

## Dreamwind

A vertical proof that decades of game data and behavior can be metabolized into a different architecture without treating compatibility as an excuse to preserve every historical implementation choice.

## R3versal

Inspection and migration tooling for the files, formats, assets, and code that old software leaves behind.
