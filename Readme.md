# DreamWeave

The DreamWeave organization site: a small Zola site for the real consultancy/engineering work and the fictional **Field Reports** archive.

The boundary is deliberate:

- **Services**, **Engineering**, and **Dispatches** describe real work.
- **Field Reports** are explicitly fictional and must never be presented as client testimonials, real engagements, or evidence for consulting claims.
- The stranger a Field Report becomes, the more ordinary the site should sound while describing it.

The site is built from the DreamWeave Mod Template, but this repository is the organization frontend rather than a mod catalog.
